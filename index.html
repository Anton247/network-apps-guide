HAPP

  1. На основном экране HAPP можно удалить все имеющиеся соединения, чтобы не запутаться. Для этого нажимайте на три точки возле карточки сервера и затем выбирайте “Удалить”.

  2. Скопируйте одну из ссылок подписки:

    https://109.206.243.105:2096/dogs/sub/shlg3tjhxepwxiiq
    https://38.180.84.205:2096/sub/tjvv8yd41iz3uhx1

  3. В правом верхнем углу нажмите плюс и выберите “Вставить из буфера обмена”.

  4. После этого появится карточка с сервером 109.206.243.105. Там будет три способа подключения. Сейчас работают XHTTP и TCP: первый и последний.

  5. Можно нажать на TCP, а затем на круглую кнопку подключения сверху приложения.

Маршрутизация HAPP

  1. Нажмите на шестеренку в левом верхнем углу и выберите “Маршрутизация”.

  2. Нажмите на три точки в правом верхнем углу и выберите “Создать новый профиль”.

  3. Нажмите на иконку обновления у “Гео-сайтов” и “Гео-айпи”, затем выберите “Редактировать правила”.

  4. Выберите режим “Напрямую”.

  5. Нажмите “Показать тэги в гео-сайтах”.

  6. В поле поиска введите “ru” и выберите все пункты, где встречается ru, например bank-ru.

  7. Вернитесь назад и сделайте то же самое для “Показать тэги в гео-айпи”. Там будет только один пункт с “ru”.

Karing

Первый запуск

  1. После установки запустите Karing. Иконка приложения выглядит так:

  2. Согласитесь с условиями использования приложения.

  3. Выберите “Русский” и нажмите “Далее” в правом верхнем углу.

  4. Экран “TV настройки” можно пропустить.

  5. Если в списке языков был выбран “Русский”, нажмите “Далее”. Если выбран другой язык, выберите “Российская Федерация”, затем нажмите “Далее”.

  6. Страницу “Шаблоны для личных правил” можно пропустить.

  7. Режим новичка можно оставить без изменений и нажать “Готово”.

Добавление профиля

  1. Скопируйте строку ниже:

    naive+https://NaiveMieuru:CgLtfvcRj07Zhald@antonytech.space:443

  2. Откройте Karing, выберите “Добавить профиль”, затем “Импорт из буфера обмена”.

  3. Заполните поле “Примечание”, например напишите “Naive”. Это просто название протокола.

  4. После добавления первого протокола можно добавить еще один. Скопируйте ссылку и вставьте ее в адресную строку браузера:

    https://disk.yandex.ru/d/k2NDc2Pzk16Cyw

  5. На странице Яндекс Диска нажмите кнопку загрузки справа от “Сохранить на Яндекс.Диск”, затем нажмите “Загрузить”.

  6. В Karing выберите “Добавить профиль”, затем “Импорт файла конфигурации” и “Выбрать файл”.

  7. В файловом проводнике нажмите на три полоски в левом верхнем углу и выберите “Загрузки”.

  8. Нажмите на три точки, выберите “Сортировать”, затем “изменениям (с новых)”. После списка папок будет файл “mieru-...”, нажмите на него.

  9. Поле “Примечание” нужно сократить до 32 символов, например оставить “mieru”. Это название протокола.

  10. На главном экране нажмите на красную круглую кнопку, чтобы включить подключение. Приложение само подберет профиль с большей скоростью.

WDTT

Этот вариант может быть полезен для учебной проверки сетевой связности в средах, где доступ организован через разрешенные списки.

  1. На основном экране приложения заполните поле “Сервер”.

    179.43.174.253

  2. Нажмите “Настройка VK Хешей” и заполните первые два поля.

    WgM9zVI5sjCt2pkgV8TUGKC9qJZgPxf62oF6WrTraL4
    7fSSkK5xQ0gQ3k_sUA129-eXzX_PK76JyGIRS3dH4kg

  3. Нажмите “Секреты” и введите пароль туннеля.

    6gszd6s3

  4. После этих действий вернитесь на главный экран и нажмите “Подключить”. Подключение срабатывает не всегда с первого раза.

    Если после нажатия доступ в интернет не появился, нажмите “Остановить”, затем снова “Подключить”. Если кнопки “Остановить” нет, сразу нажмите “Подключить” еще раз.
